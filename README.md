# Sistema de Inventario Hospitalario – Hospital San Gabriel

Aplicación web para la gestión centralizada de medicamentos, insumos médicos y materiales hospitalarios del **Hospital San Gabriel**.

## Estructura del Proyecto

- `backend/`: API REST desarrollada con Python, UV, FastAPI, Uvicorn y SQL Server (procedimientos almacenados y arquitectura por capas).
- `frontend/`: Aplicación web desarrollada con Angular.
